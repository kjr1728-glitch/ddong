# 「사연끝판왕」 장편 사연 낭독 영상 제작 기준 (확정본)

이 파일은 사용자가 확정한 제작 기준의 원문 보존본이다.
새 작품을 시작할 때 이 기준을 그대로 적용하며, 임의로 변경하지 않는다.
새 지시가 이 기준과 충돌하면 사용자가 가장 최근에 직접 내린 지시를 우선한다.

기준 작품: 「재벌 회장 장례식에 나타난 청소부 할머니가 전 재산 상속인이었습니다」
(약 66분 25초 / 6파트 / 120장면 / 1920×1080 / 승인된 A 여성 보이스)

---

## 1. 제작 방식
- Windows PC + Python + FFmpeg + TTS + 실사형 AI 이미지. InVideo 사용 금지.
- 약 60분 장편 = 약 10분 × 6파트.
- 순서: 각 파트 제작 → 1차 검수 → 오류 수정 → 2차 검수 → 통과 → 6파트 완료 후 최종 MP4 합본.
- 60분에 맞추려고 음성을 자르거나 배속하지 않는다. 이야기와 호흡 우선.

## 2. 최종 출력 규격
1920×1080 / 16:9 / 30fps / H.264 / yuv420p / MP4 / AAC 48kHz Stereo / faststart.
검은 화면·깨진 프레임·프레임 누락·싱크 오류 금지.

## 3. 이미지 움직임
모든 장면 이미지는 완전 정지. 확대·축소·이동·패닝·흔들림·Ken Burns 전부 금지.
장면이 바뀔 때만 다음 이미지로 전환.

## 4. 이미지 스타일
사진처럼 자연스러운 한국 드라마 실사. 애니·만화·일러스트·게임 그래픽·과도한 AI 느낌·
플라스틱 피부·과한 뷰티 보정 금지. 피부·조명·의상·공간·구도·표정·나이 표현이 자연스러울 것.
장면 감정과 대본 내용이 이미지에서 바로 이해될 것.

## 5. 등장인물 얼굴 일관성 (최우선)
작품 시작 시 주요 인물 기준 얼굴(reference)을 먼저 확정. 이후 전 장면에서 같은 인물은 같은 사람.
유지 요소: 얼굴형·눈·눈썹·코·입·턱·피부톤·헤어·나이·체형·분위기.
이전 작품 인물(정숙/준호/혜린/문식/수경/영식)을 재사용하라는 뜻은 아님. 작품마다 새 인물, 작품 안에서는 고정.

## 6. 얼굴·눈·손 검수
생성 성공 여부만 보지 말고 얼굴을 확대해 검사. 동공 2개, 눈 방향 불일치, 사시, 시선 어긋남,
눈동자 위치 이상, 눈꺼풀 뒤틀림, 유리알 눈, 눈 크기 좌우 차이, 얼굴 비대칭, 경계 깨짐,
다른 사람으로 변함, 목·얼굴 피부색 불일치, 나이 급변, 손가락 개수·붙음·꺾임, 몸·얼굴 연결 오류.
문제 있으면 해당 이미지만 재생성 후 재검사. 파일 열림 ≠ 품질 검수.

## 7. 다인 장면
주인공 얼굴이 조연에 복제되지 않게. 남녀 얼굴 섞임 금지. 나이 차이 유지. 한눈에 구분 가능.
회상 장면은 연령만 낮추고 동일 인물 특징 유지.

## 8. 구도
머리·얼굴·턱·중요한 손·소품 잘림 금지. 생성 단계부터 16:9 크롭 고려해 여백 확보.
무조건 확대 후 가운데 크롭 금지. 잘리면 이미지 재생성.

## 9. 자막 글꼴
Gmarket Sans TTF Bold (GmarketSansTTFBold.ttf). 변경 금지.

## 10. 자막 ASS 설정
PlayResX 1920 / PlayResY 1080 / Fontsize 62 / 흰색 / Outline 3.5 / 외곽선 매우 어두운 색 /
Shadow 1 / Alignment 2 (하단 중앙) / MarginL 160 / MarginR 160 / MarginV 112 /
ScaleX 100 / ScaleY 100 / Spacing 0 / BorderStyle 1 / WrapStyle 2

```
Style: Default,Gmarket Sans TTF Bold,62,&H00FFFFFF,&H0000FFFF,&H00101010,&H88000000,0,0,0,0,100,100,0,0,1,3.5,1,2,160,160,112,1
```

## 11. 자막 뒤 배경
x=0, y=830, w=1920, h=250, 검정, 불투명도 약 23%. 이미지를 가릴 만큼 진하게 하지 않는다.

## 12. 자막 줄바꿈
1~2줄. 의미 단위로 분리. 단어 중간 줄바꿈·조사만 넘김·한 글자 넘김·과도하게 긴 한 줄·
화면 밖 글자·좌우/하단 잘림 금지. 글자 수 자동 자르기 금지, 문장 의미를 보고 분리.

## 13. 자막 타이밍
음성 시작과 함께 등장, 대사가 완전히 끝나는 순간 함께 사라짐.
말하는 중 사라짐·마지막 음절 전 사라짐·다음 자막 조기 등장·자막 선행·음성 후 오래 남음 금지.
반드시 확인: 첫 자막, 마지막 자막, 가장 긴 자막, 2줄 자막, 각 파트 마지막 자막, 다음 파트 첫 자막.

## 14. 내레이션 목소리
사용자가 최종 선택한 A 여성 보이스 스타일. 여성 / 초기보다 낮은 톤 / 차분 / 밝거나 높은 목소리 금지 /
라디오 사연 낭독 느낌 / 또박또박 / 감정 있으나 과장 없음 / 장시간 청취 피로 없음 / 기계음 최소 / 자연스러운 호흡.
프로젝트 내부 기준: `voice = F5`, `pitch_shift = false`.
F5를 외부 TTS 서비스의 실제 보이스 ID로 임의 판단하지 않는다.

## 15. 피치 시프트 금지
높은 여성 목소리에 pitch shift로 낮은 목소리를 만들지 않는다. 원래부터 조금 낮은 여성 보이스여야 한다.
변조·로봇음 금지. 원본 승인 음성이 있으면 반드시 비교.

## 16. 말하기 속도
임의 숫자로 새로 정하지 않는다. 이전 승인본의 템포·호흡·감정·쉼표·문단 간격 기준.
길이 맞추려고 1.1배/1.2배/0.9배 등 변경 금지.

## 17. 발음 검수
생성 완료 ≠ 정상. 실제 청취로 이름·회사명·숫자·금액·날짜·외래어·연음·조사·어려운 문장·감정 대사 확인.
어색한 표현(예: 「수화기 너머」)은 의미 유지하며 문장 수정 후 해당 부분 재녹음.

## 18. 음질 검수
찢어짐·clipping·잡음·전기음·음량 급변·파트별 목소리 차이·문장 중간 끊김·단어 잘림·마지막 음절 잘림 없을 것.
ASR·디코딩 성공만으로 끝내지 않는다. 실제 청취 필요.

## 19. 대본과 장면 연결
장면 이미지는 그 시점 대본 내용과 일치. 대본 → 음성 → 자막 → 이미지가 같은 내용.

## 20. 이야기 제작 원칙
100% 창작 사연. 실존 인물·실제 기업 특정처럼 보이지 않게. 화면 안에 창작 안내 문구는 넣지 않는다.

## 21. 시작 안내 문구 (최종 결정)
「본 이야기는 실제 인물·기업·사건과 무관한 창작 사연입니다.」 문구는 넣지 않는다.
render_local.py 등에 첫 8초 Notice 코드가 남아 있어도 반드시 비활성화. 설명란 안내는 별개.

## 22. 수정 요청 처리
요청한 부분만 수정. 이미 승인된 요소(목소리·자막·타이밍·이미지·길이·속도·음악·다른 장면)는 건드리지 않는다.

## 23. 파트별 1차 검수
대본(누락·반복·문맥·인물), 음성(발음·목소리·음질·속도·누락·반복), 이미지(얼굴·눈·손·일관성·내용 일치·잘림),
자막(오탈자·줄바꿈·크기·위치·잘림·싱크).

## 24. 파트별 2차 검수
렌더된 실제 영상에서 정지 여부, 자막 잘림, 자막 조기 소멸, 음성·자막 일치, 수정 이미지 반영, 파트 시작·종료 자연스러움.

## 25. 최종 합본 검수
길이·1920×1080·30fps·H.264·오디오 존재·싱크·전체 디코딩·검은 화면·프레임 누락·파트 사이 공백·
자막 연결·첫 장면·마지막 장면. "파일이 만들어졌다"는 완료가 아니다.

## 26. 검수 보고 정직성
샘플만 봤으면 전체를 봤다고 하지 않는다. 끝까지 듣지 않았으면 청취 검수했다고 하지 않는다.
검사한 범위와 못 한 범위를 구분해 보고. 오류 0%를 확인 못 했으면 보장하지 않는다.

## 27. 작업 중단 대비
최종 대본, 장면별 대본, 장면 이미지, 인물 reference, TTS 음성, 음성 설정, ASS/SRT, 폰트, 렌더 코드,
FFmpeg 설정, 검수 결과, 수정 완료 지점, 파트별 완성 파일을 지속 저장. 재시작 시 이어서 진행.

## 28. 이전 최종본 참고 수준
약 66분 25초 / 6파트 / 120장면 / 인물 장면 112개 얼굴 교정 / 1920×1080 / 전체 디코딩 통과 / 정지 이미지 통과.
숫자를 똑같이 맞출 필요는 없다. 품질 수준과 제작 방식을 동일하게 유지하는 것이 목적.

## 29. 최종 결과물
최종 1080p MP4, 필요 시 ZIP, 바로 누를 수 있는 다운로드 링크. 임시 경로만 알려주고 끝내지 않는다.

## 30. 절대 규칙 요약
- 영상: 1920×1080 / 16:9 / 30fps / H.264 / MP4
- 이미지: 한국 드라마 실사, 완전 정지, 확대·이동·흔들림 없음
- 인물: 작품별 기준 얼굴 고정, 전 장면 일관성, 눈·동공·시선·손·피부·나이 검수
- 자막: Gmarket Sans TTF Bold 62 흰색 Outline 3.5 Shadow 1 하단 중앙 Margin 160/160/112, 1~2줄 의미 단위, 대사 종료와 동시 종료
- 목소리: A 여성 보이스, 낮은 여성 톤, 라디오 낭독 느낌, pitch shift 금지, 무단 배속 금지, 실제 청취 검수
- 시작 화면: 창작 안내 문구 없음
- 제작: Python + FFmpeg + TTS + AI 이미지, InVideo 금지, 약 10분 × 6파트, 1차 검수 → 수정 → 2차 검수 → 합본
- 수정: 요청한 부분만
