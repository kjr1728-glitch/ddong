# 영상 파일 넣는 곳

여기에 아래 이름 그대로 영상 파일을 넣어주세요. 파일명이 코드에 이미 연결되어 있어서,
이름만 맞으면 바로 재생됩니다.

- greeting.mp4      → "연화의 사주" 카드 클릭 시 바로 재생되는 인사 영상 (현재 적용됨)
- ask-name.mp4      → "무엇이라 불러드릴까요?" 질문 영상 (아직 없음, 나중에 추가)
- ask-gender.mp4    → "성별을 알려주세요" 질문 영상 (아직 없음)
- ask-date.mp4      → "태어난 날짜가 언제예요?" 질문 영상 (아직 없음)
- ask-time.mp4      → "태어난 시각도 알면..." 질문 영상 (아직 없음)
- ask-question.mp4  → "특별히 궁금한 점이 있다면..." 질문 영상 (아직 없음)

영상이 없는 단계는 자동으로 원래의 말풍선 방식으로 넘어가니,
하나씩 채워 넣어도 문제없습니다. ask-name.mp4 등을 추가하려면
코드에서 해당 문답 단계에 video 속성을 다시 넣어주면 됩니다 (요청 시 반영).

## 용량 관련 팁
- 세로형(9:16) 영상 추천 — 화면 전체를 덮는 방식이라 세로 영상이 잘 맞아요.
- 파일 하나당 5~10MB 이내로 압축하는 걸 추천해요 (HandBrake 같은 무료 툴로 변환 가능).
  너무 크면 재생이 느려서 사용자가 답답해할 수 있어요.
- GitHub 웹 업로드는 파일당 25MB까지 가능해요.
