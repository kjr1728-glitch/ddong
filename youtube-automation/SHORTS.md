# 쇼핑 쇼츠 자동 제작

쿠팡 파트너스 상품으로 세로 쇼츠를 만들고, 원하면 유튜브에 자동으로 올립니다.

## 먼저 아셔야 할 세 가지

**1. 수수료 고지는 법에서 요구하는 사항입니다.**
"이 영상은 쿠팡 파트너스 활동의 일환으로 수수료를 제공받습니다" 문구를
영상 안과 설명란 양쪽에 자동으로 넣습니다. 끄는 옵션은 두지 않았습니다.
빠뜨리면 파트너스 계정이 정지되고 표시광고법 위반이 됩니다.

**2. 하루 3개 자동 업로드는 유튜브 정책상 위험이 있습니다.**
비슷한 형식의 영상을 기계로 대량 생산해 올리면 "반복성 콘텐츠"로 분류되어
수익 창출 승인이 거절될 수 있습니다. 쿠팡 수수료만 노린다면 큰 문제가
아니지만, 유튜브 광고 수익까지 생각하신다면 편수를 줄이고 영상마다
직접 손보시는 편이 안전합니다.

**3. 심사 전에는 자동 업로드한 영상이 비공개로 잠깁니다.**
구글이 업로드 권한을 쓰는 앱에 심사를 요구합니다. 심사를 받기 전에는
이 도구로 올린 영상이 비공개 상태가 되며, 유튜브 스튜디오에서 직접
공개로 바꿔야 합니다. 이 도구의 기본 설정도 비공개입니다.

## 승인 단계를 먼저 아셔야 합니다

쿠팡 파트너스는 승인이 두 단계입니다. **API는 두 번째 단계를 통과해야 열립니다.**

| 단계 | 조건 | 할 수 있는 것 |
|---|---|---|
| 가입 / 임시 승인 | 가입 신청만 하면 됩니다 | 사이트에서 직접 추천 링크 생성 |
| 최종 승인 | 누적 판매 **15만원** + 활동 채널 등록 | 정산 받기, **API 키 발급** |

즉 처음에는 API를 쓸 수 없습니다. 영상을 올려 매출 15만원을 먼저 만들어야
자동화가 열리는 구조입니다. 그래서 두 가지 방법을 준비해뒀습니다.

- **최종 승인 전**: 상품을 직접 골라 넣습니다 (아래 "직접 골라 만들기")
- **최종 승인 후**: `shorts.py`가 알아서 골라옵니다 (아래 "자동으로 만들기")

만드는 영상의 모양은 두 방법이 똑같습니다. 상품을 누가 고르느냐만 다릅니다.

## 직접 골라 만들기 (최종 승인 전)

### 1. 쿠팡 파트너스 가입
partners.coupang.com에서 가입합니다. 보통 하루 이틀이면 임시 승인이 납니다.
이 상태에서도 사이트에서 상품별 추천 링크를 만들 수 있습니다.

### 2. 상품 고르고 자료 모으기
쿠팡에서 팔고 싶은 상품을 찾아 두 가지를 챙기세요.

- **대표 이미지**: 상품 페이지에서 이미지를 오른쪽 클릭해 저장
- **내 추천 링크**: 파트너스 사이트의 링크 생성기로 만든 주소

이미지는 `assets/my_products/` 폴더에 넣습니다.

### 3. 목록 파일 채우기
```bash
python scripts/manual_products.py
```
처음 실행하면 `assets/my_products/products.csv` 서식이 만들어집니다.
엑셀이나 메모장으로 열어 한 줄에 상품 하나씩 적으세요.

```
이미지파일,상품명,가격,링크,로켓배송
fan.jpg,접이식 휴대용 미니 선풍기,12900,https://link.coupang.com/a/AAA,Y
holder.jpg,차량용 각도조절 휴대폰 거치대,8900,https://link.coupang.com/a/BBB,
```

첫 줄은 그대로 두세요. 잘못 적은 줄이 있으면 몇 번째 줄이 왜 문제인지 알려줍니다.

### 4. 영상 만들기
```bash
python shorts.py --manual
python shorts.py --manual --upload
```

### 상품 고르실 때 참고
자동 선별기가 쓰는 기준과 같습니다. 사람이 고를 때도 이 기준이 먹힙니다.

- 7천원에서 4만원 사이. 충동구매가 일어나는 구간입니다.
- 이름이 짧아 1~2초 안에 읽히는 것
- 접이식, 무선, 자동, 각도조절, 틈새처럼 "저게 뭐지" 싶은 물건
- 로켓배송. 바로 받을 수 있어야 구매로 이어집니다.
- 생수, 화장지, 세제 같은 반복구매 생필품은 피하세요. 호기심이 안 생깁니다.

## 자동으로 만들기 (최종 승인 후)

### 1. API 키 발급
최종 승인을 받으면 파트너스 사이트에서 "내 정보 → 오픈 API 키 발급"으로
키 두 개를 받아 `.env`에 넣습니다.

```
COUPANG_ACCESS_KEY=발급받은키
COUPANG_SECRET_KEY=발급받은비밀키
```

키가 제대로 동작하는지 확인:
```bash
python scripts/coupang_client.py
```
골드박스 상품 목록이 나오면 됩니다. 401이 나오면 키가 틀렸거나
컴퓨터 시계가 어긋난 것입니다. 시계는 몇 분만 틀려도 인증이 거부됩니다.

### 2. 배경음악 넣기
`assets/music` 폴더에 음악 파일을 하나 넣어두세요. 자세한 건 그 폴더의 README를 보세요.

## 사용법

```bash
# 영상 3개 만들기 (업로드 안 함)
python shorts.py

# 만들고 비공개로 올리기까지
python shorts.py --upload

# 영상 5개, 영상마다 상품 4개
python shorts.py --videos 5 --per-video 4
```

결과는 `output/shorts/<날짜>/`에 들어갑니다.
영상 파일과 함께 제목·설명란이 `meta_*.json`에 저장되니,
직접 올리실 때는 그 내용을 복사해 쓰시면 됩니다.

## 상품은 어떻게 고르나

`scripts/product_picker.py`가 골드박스와 카테고리 베스트에서 후보를 모은 뒤
점수를 매겨 고릅니다. 기준은 이렇습니다.

- **가격**: 7천원~4만원대를 높게 봅니다. 충동구매가 일어나는 구간입니다.
  3천원 미만이나 9만원 초과는 아예 제외합니다.
- **이름 길이**: 짧을수록 높게 봅니다. 1~2초 안에 읽혀야 하기 때문입니다.
- **호기심 단어**: 접이식, 무선, 자동, 각도조절, 틈새, 센서 같은 말이
  들어가면 가산점을 줍니다. "어? 저게 뭐야" 소리가 나오는 물건들입니다.
- **로켓배송**: 가산점. 바로 받을 수 있어야 구매로 이어집니다.
- **제외**: 생수, 화장지, 세제처럼 반복 구매하는 생필품은 영상으로 만들어도
  호기심이 생기지 않아 거릅니다.
- **중복 방지**: 한 번 쓴 상품은 `output/.used_products.json`에 기록해
  다시 고르지 않습니다.

기준을 바꾸고 싶으면 `product_picker.py` 맨 위의 목록과 숫자를 고치면 됩니다.

## 영상은 어떻게 생겼나

상품 이미지가 한 장뿐이라 그것만으로 세로 화면을 채워야 합니다.

- 배경은 같은 이미지를 크게 확대하고 흐리게 깔아 세로 화면을 채웁니다.
  검은 여백을 남기는 것보다 훨씬 완성돼 보입니다.
- 상품은 가운데에 선명하게 얹고 아주 느리게 확대합니다.
- 맨 위에 훅 문구, 아래에 상품 이름과 가격을 넣습니다.
- 상품 여러 개를 이어 붙입니다. 한 개만 계속 보여주면 금방 나가버립니다.
- 마지막 화면에 링크 안내와 수수료 고지가 들어갑니다.

## 매일 자동으로 돌리기

```bash
crontab -e
# 매일 오전 8시
0 8 * * * cd /path/to/youtube-automation && python shorts.py --upload >> shorts.log 2>&1
```

윈도우는 작업 스케줄러를 쓰면 됩니다.

**업로드 할당량**: 영상 하나 올리는 데 1,600 유닛이 듭니다. 무료 한도가
하루 10,000이라 상품 조회까지 합치면 하루 5개 정도가 현실적인 상한입니다.

## 잘 안될 때

- **401 인증 실패**: 키를 다시 확인하고, 컴퓨터 시계를 인터넷 시간과 맞추세요.
- **쓸 만한 상품이 없다고 나옴**: 이미 다 써버린 것입니다.
  `output/.used_products.json`을 지우거나 `--categories`로 다른 카테고리를 넣으세요.
- **영상에 글자가 안 나옴**: 한글 폰트를 못 찾은 것입니다.
  `--font "C:\Windows\Fonts\malgunbd.ttf"` 처럼 직접 지정하세요.
- **나레이션 403**: edge-tts 문제입니다. README의 해당 항목을 보세요.
  급하면 `--no-narration`으로 음악만 넣어 만들 수 있습니다.
