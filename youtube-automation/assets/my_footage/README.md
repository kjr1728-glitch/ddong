# 직접 찍은 영상 넣는 곳

상품마다 폴더를 하나 만들고, 그 안에 찍은 영상을 넣으세요.

```
assets/my_footage/
  선풍기/
    01.mp4
    02.mp4
    03.mp4
    script.txt
  칫솔살균기/
    ...
```

## 어떻게 찍으면 되나

참고하신 영상을 분석해보니 이렇게 돼 있었습니다. 특별한 장비 없이
폰으로 집에서 찍은 것이었습니다.

- **손이 나와야 합니다.** 물건만 덩그러니 놓고 찍으면 상세페이지 사진과
  다를 게 없습니다. 집어 들고, 만지고, 누르고, 여는 손이 나와야
  "저거 써보고 싶다"가 됩니다.
- **짧게 여러 개 찍으세요.** 한 번에 길게 찍는 것보다 5~10초짜리를
  10개쯤 찍는 게 낫습니다. 도구가 알아서 0.6~0.9초로 잘라 씁니다.
- **각도를 바꿔가며 찍으세요.** 위에서, 옆에서, 가까이서. 같은 각도만
  있으면 아무리 잘라 붙여도 지루합니다.
- **밝은 곳에서 찍으세요.** 창가 낮이 제일 낫습니다. 형광등 아래는
  색이 누렇게 나옵니다.
- **세로로 찍으세요.** 가로로 찍으면 위아래가 잘립니다.
- **소리는 신경 쓰지 않아도 됩니다.** 어차피 나레이션과 음악으로 덮습니다.

### 꼭 찍어야 할 장면

1. 포장을 뜯거나 처음 꺼내는 순간
2. 손에 쥐고 이리저리 살펴보는 모습
3. **실제로 쓰는 장면** — 이게 제일 중요합니다
4. 크기를 가늠할 수 있는 장면 (손바닥에 올리기, 주머니에 넣기)
5. 특징을 보여주는 장면 (방수면 물에 대보기, 접히면 접어보기)

30초에서 1분 정도 분량이면 충분합니다.

## script.txt 쓰는 법

한 줄에 한 문장씩 적으세요. 이게 그대로 나레이션이 되고 자막이 됩니다.

```
이거 하나로 세안이 끝납니다.
손에 쥐는 순간 느낌이 다릅니다.
방수까지 완벽합니다.
가지고 다니기 너무 좋습니다.
```

짧게 쓰세요. 한 문장이 길면 자막이 두 줄로 넘어가 화면을 가립니다.
말하듯이 쓰되 너무 과장하지 마세요. 광고 티가 나면 바로 넘겨버립니다.

## 만들기

```bash
# 1) 나레이션 만들기
python scripts/narration.py --script assets/my_footage/선풍기/script.txt \
    --output assets/my_footage/선풍기/narration.mp3

# 2) 영상 만들기
python scripts/footage_shorts.py --footage-dir assets/my_footage/선풍기 \
    --output output/shorts/선풍기.mp4
```

나레이션 mp3와 같은 이름의 .srt가 함께 만들어지고, 그 타이밍에 맞춰
자막이 붙습니다.

## 저작권 주의

**판매자 상세페이지 영상을 받아서 쓰지 마세요.** 저작권 침해입니다.
이런 채널이 많지만 신고가 쌓이면 경고를 받고 반복되면 채널이 삭제됩니다.
직접 찍으시거나, 판매자에게 사용 허락을 받으세요.
