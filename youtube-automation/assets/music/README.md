# 배경음악 넣는 곳

이 폴더에 음악 파일(.mp3, .m4a, .wav, .ogg)을 하나 넣어두면
영상 합성할 때 자동으로 나레이션 밑에 작게 깔립니다.
나레이션을 덮지 않도록 원래 크기의 10% 정도로 줄여서 넣고,
영상 끝에서 자연스럽게 사라지게 합니다.

음악을 넣고 싶지 않으면 이 폴더를 비워두거나 `--no-music`을 붙이세요.
파일이 여러 개면 이름 순으로 첫 번째 것을 씁니다.

## 저작권 걱정 없는 무료 음악 구하는 곳

- **유튜브 오디오 보관함** — 유튜브 스튜디오에 로그인한 뒤 왼쪽 메뉴에서
  "오디오 보관함"으로 들어가면 됩니다. 유튜브가 직접 주는 음악이라
  저작권 문제가 가장 확실하게 없습니다. 여기를 제일 먼저 보세요.
  (다운로드할 때 "저작자 표시 필요" 표시가 있는 곡은 영상 설명란에
  표기를 넣어야 하니, 표시가 없는 곡을 고르는 쪽이 편합니다.)
- **Pixabay Music** — https://pixabay.com/music/ 가입 없이 받을 수 있습니다.
- **Free Music Archive** — https://freemusicarchive.org 곡마다 이용 조건이
  다르니 라이선스를 확인하세요.

## 고르는 요령

말을 가리지 않는 잔잔한 곡이 좋습니다. 드럼이 세거나 멜로디가 튀는 곡은
나레이션과 싸워서 오히려 듣기 나빠집니다. 검색할 때 ambient, cinematic,
background, lo-fi 같은 말을 붙이면 맞는 곡이 잘 나옵니다.
