# 장면 전환 효과음 넣는 곳

이 폴더에 짧은 효과음 파일(.wav, .mp3, .m4a)을 하나 넣어두면
상품이 바뀌는 순간마다 자동으로 깔립니다.

**비워두셔도 됩니다.** 파일이 없으면 프로그램이 간단한 "쉭" 소리를 직접
만들어 씁니다(`_whoosh.wav`로 저장됩니다). 그럴듯하지만 밋밋하니,
마음에 드는 소리를 구해 넣으시면 훨씬 낫습니다.

효과음을 아예 빼려면 `--no-sfx`를 붙이세요.

## 무료 효과음 구하는 곳

- **유튜브 오디오 보관함** — 유튜브 스튜디오 → 오디오 보관함 → "음향 효과" 탭.
  저작권 문제가 가장 확실하게 없습니다. 여기를 먼저 보세요.
- **Pixabay** — https://pixabay.com/sound-effects/ 가입 없이 받을 수 있습니다.
- **Freesound** — https://freesound.org 곡마다 이용 조건이 다르니 확인하세요.

## 고르는 요령

"whoosh", "swoosh", "transition", "pop" 으로 검색하세요.
길이는 0.2~0.5초가 적당합니다. 1초를 넘어가면 나레이션을 덮어버립니다.
소리가 너무 크면 알아서 35%로 줄여서 넣으니 신경 쓰지 않으셔도 됩니다.
